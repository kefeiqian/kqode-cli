# Archived TUI Documents

This directory preserves KQode's early terminal UI requirements, plans, research,
and implementation notes.

These documents are historical. KQode is now a desktop-first coding agent
application built with React and Tauri. The Rust runtime also supports CLI and
headless execution, but the product does not provide a TUI.

Statements in this directory that describe KQode as terminal-first, refer to the
removed `tui/` package, or assign current product behavior to an Ink interface
reflect the design at that time and are not current requirements.
